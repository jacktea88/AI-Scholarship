# 專案導覽

## 1. 這是什麼

NCUE 獎助學金資訊平台，功能包括公告瀏覽、訂閱提醒、Gemini AI 助理、LINE 官方帳號整合與管理後台。

## 2. Monorepo 結構

| 路徑 | 說明 |
| :--- | :--- |
| `apps/web` | Next.js 16（App Router），前後端加 API Routes |
| `apps/mobile` | Expo / React Native App |
| `packages/core` | 共用 TypeScript，例如 `siteConfig`、`studentId`、`aiKey`、`line`、`retryFetch` |
| `apps/web/supabase` | 資料庫 schema 與 migrations |
| `docs` | 使用手冊與本導覽 |

## 3. 關鍵入口

- **品牌設定**：`packages/core/src/siteConfig.ts`、`apps/web/src/lib/siteConfig.js`
- **AI 核心**：`apps/web/src/lib/ai/`
  - `agent.js`：提示詞與工具迴圈
  - `tools.js`：工具宣告與實作
  - `knowledge.js`：知識庫與向量搜尋
  - `models.js`：模型名稱
  - `memory.js`：使用者背景記憶
  - `userKey.js`：使用者自備金鑰
- **網頁對話 API**：`apps/web/src/app/api/chat`
- **LINE**：`apps/web/src/app/api/line/webhook/route.js`、`apps/web/src/lib/line.js`
- **設定讀取**：`apps/web/src/lib/config.js` 的 `getSystemConfig`，先讀資料庫 `system_settings`，再讀環境變數
- **路由保護**：`apps/web/middleware.js`
- **排程**：`api/cron/deadline-notify`，需 `CRON_SECRET`

## 4. 主要資料流

- **LINE 訊息**：驗簽 → 綁定檢查 → 每分鐘 5 次限流 → 排程檢查 → `handleAiReply` → `runScholarshipAgentText`（工具迴圈最多 6 輪）→ 回覆或推播。
- **公告知識庫**：公告建立或更新 → `syncAnnouncementKnowledge` → `ai_knowledge`（含 embedding）→ `searchKnowledge`。

## 5. 主要資料表

`ai_knowledge`、`ai_knowledge_gaps`、`chat_history`、`line_users`、`line_messages`、`line_bind_codes`、`profiles`、`user_ai_keys`、`announcement_subscriptions`、`system_settings`

## 6. 常用指令

```bash
npm install
npm run dev
npm run build
npm run lint
npm run mobile:dev
```

## 7. 新增 AI 工具

1. 在 `tools.js` 的 `toolDeclarations` 加宣告。
2. 在 `executors` 加實作。
3. 在 `describeToolCall` 加顯示文字。
4. 動作類工具要在 `agent.js` 的 `TOOL_CALL_LIMITS` 加上限，並在提示詞補同意規則。
